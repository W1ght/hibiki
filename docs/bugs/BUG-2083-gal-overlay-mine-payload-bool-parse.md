## BUG-2083 · 覆盖窗制卡 payload 把 bool 字符串化后 fromJson 用 as bool? 直接抛，制卡全灭
- **报告**：2026-09-03（适配 KiriKiri Z 新样本 lapla.exe 真机制卡时发现；用户截图可见查词卡正常渲染在游戏上、点「+」后弹「导出卡片失败：Invalid card data (payload parse failed): type 'String' is not a subtype of type 'bool?' in type cast」）
- **真实性**：✅ 真 bug。根因 `packages/fushi_anki/lib/src/anki_models.dart:561`（原 `glossarySelectionHighlighted: json['glossarySelectionHighlighted'] as bool? ?? false`）。覆盖窗查词浮窗（桌面 global lookup **与** galgame 游戏内内嵌查词）的制卡桥 `fushi/lib/src/lookup/overlay_bridge_handlers.dart:330-333` 把 popup.js 送来的整份 payload 收敛成 `Map<String, String>`（`e.value?.toString()`），于是 popup.js 里的 `glossarySelectionHighlighted`（bool）在到 `AnkiMiningPayload.fromJson` 前已被 `toString()` 成字符串 `"false"`/`"true"`；`as bool?` 对字符串抛 `type 'String' is not a subtype of type 'bool?'`，被 `AnkiConnectRepository._mineEntryInner`（`ankiconnect_repository.dart:678`）捕成 `MineOutcome.failure('Invalid card data (payload parse failed): …')`。结果：**任何经覆盖窗桥的制卡都停在这一步、一张卡都写不出**。真机堆栈 `error_log.txt`：`new AnkiMiningPayload.fromJson (anki_models.dart:561:48) ← _mineEntryInner:678 ← mineEntry:620 ← GalHookMiningCoordinator._mineLineNow`。ankidroid / ankimobile 两个 repo 的同名解析路径（`anki_repository.dart` / `ankimobile_repository.dart`）走同一个 `AnkiMiningPayload.fromJson`，同受影响。
- **[x] ① 已修复** — `packages/fushi_anki/lib/src/anki_models.dart`：新增 `_asFlexibleBool`，`glossarySelectionHighlighted` 改用它解析——保留原生 bool、把字符串 `"true"`/`"1"`（及非零 num）视为真，其余（含缺失/空串/`"false"`）为假；不再对覆盖窗桥的字符串化 bool 抛类型异常。修在解析层而非桥层，因为「payload 往返只保证字符串」是覆盖窗桥的既定契约（handler 签名就是 `Map<String, String>`），解析层容错才是根因修复。真机复测 2026-09-03（lapla.exe，游戏内点「微細」→ 卡上「+」）：AnkiConnect 新增真卡。
- **[x] ② 已加自动化测试** — `fushi/test/anki/anki_models_test.dart` 新增 group「AnkiMiningPayload.fromJson glossarySelectionHighlighted (BUG-2082)」：① 覆盖窗桥字符串化 `"false"` 经 jsonEncode/decode 往返后 fromJson 不抛、值为 false；② 字符串 `"true"`/`"1"` 解析为 true；③ 原生 bool 与缺失键仍正确。
- **备注**：与 BUG-2081（内嵌查词行号解析跨 provider 落空）叠加——两者都在 galgame 内嵌制卡链上，2081 让 resolver 拿到 lineId，2083 让 Anki 写入不再解析失败，缺一不可。此 bug 不限 galgame：桌面 global lookup 覆盖窗制卡同样受影响。
